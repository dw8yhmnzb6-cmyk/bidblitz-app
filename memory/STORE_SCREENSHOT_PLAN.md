# BidBlitz Screenshot Plan

- Only store-safe build
- No auctions or gambling UI
- No fake money
- No unrealistic high balances

3. QR Pay / Scan
4. POS / Merchant cashier
5. Invoice / Payment link
6. Staff / Business tools
7. Taxi / Mobility
