# BidBlitz Privacy Answers Draft

## Apple Privacy Nutrition Labels / Google Data Safety Summary

### Data collected
- Account identifiers
- Contact information
- Payment-related references and transaction history
- User ID
- Device and diagnostics data
- Location (only when mobility/taxi is used)
- Photos/documents (only when upload/KYC is used)

### Data linked to user
- Account info: Yes
- Contact info: Yes
- Payment info: Yes
- Purchase history: Yes
- User ID: Yes
- Device identifiers: Yes
- Location: Yes, when used
- Photos / documents: Yes, when used

### Data used for app functionality
- Wallet, QR Pay, POS, invoices, mobility, support, account management

### Data used for fraud prevention / security
- Account and device signals
- Payment and transaction monitoring
- KYC document validation where applicable

### Data sale
- No data is sold to third parties
